<div slot="release">

```sh
curl -fsSL https://raw.githubusercontent.com/casoon/site-scraper/main/install.sh | bash
```

The installer detects the platform and installs the latest release to `~/.local/bin` unless
`INSTALL_DIR` is set. Release binaries exist for Linux (x86_64, arm64) and macOS on Apple silicon
(arm64); on any other platform, use Cargo or build from source.

</div>
<div slot="cargo">

```sh
cargo install --git https://github.com/casoon/site-scraper
```

</div>
<div slot="source">

```sh
git clone https://github.com/casoon/site-scraper.git
cd site-scraper
cargo install --path .
```

</div>
</Tabs>

## Headless support

Release binaries include headless support. A local source build needs the feature explicitly:

```sh
cargo build --release --features headless
```

Headless crawling and screenshots also require Chrome or Chromium on the machine. Standard HTTP
crawls do not.

## Verify the install

```sh
site-scraper --version
# site-scraper 1.4.6
```
